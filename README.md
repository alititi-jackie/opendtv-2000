# opendtv-2000 · OpenDTV 旧站存档

2000 年前后 opendtv.com 旧站（OpenDTV 社群站，Pcube Labs 运营）的静态存档，从 Internet Archive Wayback Machine 的存档快照恢复。

- 首页 index.html 为 2000-05-10 快照（带论坛 / Hot Shots / Hot Products 导航的完整版）
- index-20000301.html 为 2000-03-01 的首页快照（早期版），原样保留
- 其余页面：forum.html、hotshots.html、hotproducts.html、BigPix.html、Progressive.html、What If.html、DigitalTV shopping.html
- secure/members.html 当年为密码保护区，存档里只有 401 提示页；secure/participants.html 是当年公开的参与者名单，内容完整
- Download Files/ 里是当年站上提供的 PDF、PPT 与 QuickTime 视频原件

站内链接已改写为本地相对链接。当年未被存档的图片（论坛页的赞助商标志、个别文章配图等共 18 张）无法恢复，相关位置会显示缺图，文字内容完整。
